¿Cómo usar Shizuku?

  1. Instala Shizuku: Descarga el APK desde el enlace de descarga y sigue el asistente de instalación.
  2. Abre la aplicación: Ejecuta Shizuku en tu dispositivo Android.
  3. Sigue las instrucciones: La app te guiará para conectar mediante ADB (Android Debug Bridge). Si no tienes experiencia, la interfaz tiene guías visuales paso a paso.
  4. Otorga permisos: Una vez conectado, dale permisos de sistema a las apps que quieras usar (gestor de aplicaciones, utilidades, módulos, etc.).
💡 ¿Para qué sirve?

Shizuku permite a apps acceder a APIs de sistema de Android sin necesidad de root. Es la base de muchas herramientas avanzadas: debloat, control de sistema, automation, limpieza y optimización.

⚠️ Importante: Requiere conectar el teléfono a una computadora con ADB instalado para la configuración inicial. Una vez activado, no necesita la computadora.

¿Cómo usar Magisk?

  1. Descargar APK: Descarga el archivo Magisk.apk desde el enlace en la tarjeta.
  2. Instalar: Abre el APK e instala la aplicación en tu dispositivo.
  3. Primer inicio: Magisk te pedirá confirmar la instalación del binario de root. Toca "Instalar" y espera a que reinicie el dispositivo.
  4. Verificar instalación: Una vez reiniciado, abre Magisk nuevamente. Si ves "Instalado" en la tarjeta de versión, ¡listo! Tienes root.
  5. Instalar módulos: Descarga módulos desde repositorios conocidos (Magisk Modules Repository) e instálalos desde Magisk. Algunos requieren reinicio.
🔓 ¿Qué es root?

Root es acceso administrativo total a tu dispositivo Android. Con Magisk, obtienes root de forma "systemless" (sin modificar el sistema), lo que te permite personalizar tu dispositivo, realizar copias de seguridad completas y instalar herramientas avanzadas de automatización.

⚠️ Riesgos: Root puede romper apps, vulnerar seguridad bancaria o dañar el sistema. Instala solo módulos de fuentes confiables.

¿Cómo usar KernelSU?

  1. Requisitos: Tu dispositivo debe tener un kernel compatible con GKI (Generic Kernel Image). Verifica en la documentación oficial de KernelSU.
  2. Descarga APK: Obtén la app desde el enlace en la tarjeta.
  3. Instala: Abre el APK e instala KernelSU.
  4. Primera vez: La app te guiará para reemplazar el kernel. Esto puede requerir acceso de root previo o instalador personalizado.
  5. Verifica estado: Abre KernelSU. Si aparece "Sudomod instalado", tienes root activo.
⚡ ¿Diferencia con Magisk?

KernelSU opera a nivel de kernel, lo que reduce huellas detectables en apps bancarias. Es más moderno pero requiere kernel compatible. Magisk es más universal.

⚠️ Compatibilidad: No todos los dispositivos soportan KernelSU. Verifica antes de intentar instalar.

¿Cómo usar LSPosed?

  1. Requisitos previos: Necesitas root activo (Magisk o KernelSU) instalado en tu dispositivo.
  2. Descarga LSPosed: Obtén el archivo de módulo de Magisk desde el enlace en la tarjeta.
  3. Instala como módulo: Abre Magisk → Módulos → (+) → Selecciona el archivo de LSPosed → Instala.
  4. Reinicia: Después de instalar, reinicia el dispositivo.
  5. Abre LSPosed: Una vez reiniciado, busca "LSPosed" en tus apps. Aparecerá en el menú como una nueva aplicación.
  6. Descarga módulos Xposed: En LSPosed, descarga módulos desde el mercado integrado e actívalos en sus apps correspondientes.
🧩 ¿Qué es Xposed?

Xposed es un framework que permite módulos modificar el comportamiento de otras apps sin tocar archivos del sistema. LSPosed es la versión moderna para Android actual.

⚠️ Importante: Requiere root y Magisk/KernelSU. Módulos malos pueden romper el sistema. Instala solo desde fuentes confiables.

¿Cómo usar App Manager?

  1. Instala la app: Descarga desde el enlace y abre el APK.
  2. Primer inicio: App Manager pedirá permisos. Dale acceso de "Uso especial" en Ajustes → Permisos especiales → Acceso especial de app (en cada Android es diferente).
  3. Opcional - Shizuku: Para funciones avanzadas (debloat, backup), conecta con Shizuku siguiendo sus instrucciones.
  4. Navega la interfaz: Verás todas las apps instaladas. Toca cualquiera para ver permisos, componentes, tamaño, versión y firma.
  5. Usa funciones: Puedes desinstalar, congelar, eliminar datos, hacer backups y revisar permisos peligrosos.
🔍 ¿Qué puedes hacer?

Ver permisos que cada app solicita, identificar apps del sistema innecesarias, hacer backup de APKs, analizar firmas y componentes exportados, debloat seguro con Shizuku.

⚠️ Ten cuidado: No desinstales apps del sistema a menos que sepas qué hacen. Mejor congelarlas primero.

¿Cómo usar Echo Nightly?

  1. Descarga e instala: Obtén el APK desde el enlace en la tarjeta. Es una build nightly (experimental).
  2. Abre Echo: Al iniciar, añade fuentes de música. Puedes usar Spotify, YouTube Music, streaming local, etc.
  3. Instala extensiones: Ve a Ajustes → Extensiones → (+) → Pega el raw de extensiones o URL JSON.
  4. Usa el botón en la tarjeta: Toca "Copiar extension de pluhings" para copiar la URL oficial de extensiones Echo.
  5. Disfruta: Una vez activas las extensiones, reproducemusica libremente.
🎵 ¿Qué son las extensiones?

Las extensiones agregan nuevas fuentes de música a Echo. Pueden ser plugins para Spotify, YouTube, SoundCloud, etc. Cada extensión amplía lo que puede reproducir.

ℹ️ Nota: Echo Nightly es experimental. Puede tener bugs. Si quieres estabilidad, usa la versión estable en Google Play.
