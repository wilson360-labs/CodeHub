01 Aceptación de los términos

Al acceder y usar el sitio web wilson360-labs.vercel.app («CodeHub», «el Sitio»), aceptas quedar vinculado por estos Términos de Uso. Si no estás de acuerdo con alguna parte de estos términos, te pedimos que no uses el Sitio.

Estos Términos de Uso se aplican a todos los visitantes, usuarios y cualquier otra persona que acceda o use el Sitio.

02 Descripción del servicio

CodeHub es un portfolio personal y hub de herramientas web operado por Wilson.E, desarrollador web autodidacta de Guatemala. El Sitio ofrece:

  • Portfolio profesional con información sobre proyectos y servicios freelance
  • Más de 23 herramientas web gratuitas (generadores, convertidores, utilidades de código)
  • Chatbot con inteligencia artificial (EMI IA) para asistencia técnica general
  • Blog de desarrollo web (codehub-labs.blogspot.com)
  • Información sobre aplicaciones de terceros para Android
  • Información de clima en tiempo real basada en tu ubicación
  • Formulario de contacto para consultas de proyectos freelance

03 Uso permitido

✅ Puedes: usar el Sitio para fines personales, educativos y profesionales legítimos.
  • Usar las herramientas web gratuitas para tus proyectos personales o profesionales
  • Contactar al operador para consultas sobre servicios freelance
  • Compartir el sitio o sus herramientas con otras personas
  • Leer y compartir el contenido del blog con atribución al autor
  • Instalar la aplicación web progresiva (PWA) en tu dispositivo
  • Usar el chatbot EMI IA para obtener ayuda técnica y de programación

04 Uso prohibido

🚫 No puedes usar este Sitio de manera que viole leyes aplicables o derechos de terceros.

Queda estrictamente prohibido:

  • Ataques y abuso técnico: intentar hackear, sobrecargar (DDoS), acceder de forma no autorizada o explotar vulnerabilidades del Sitio o su infraestructura.
  • Scraping masivo: usar bots automatizados para extraer contenido del Sitio de forma masiva sin autorización expresa.
  • Spam y phishing: usar el formulario de contacto o cualquier otra función del Sitio para enviar mensajes no solicitados o engañosos.
  • Distribución de malware: usar el Sitio como vector para distribuir software malicioso.
  • Uso comercial no autorizado del contenido: reproducir, revender o explotar comercialmente el código, diseño o contenido de CodeHub sin permiso escrito del operador.
  • Suplantación: hacerse pasar por el operador o afirmar una relación oficial con CodeHub sin autorización.
  • Actividades ilegales: cualquier uso del Sitio que viole leyes locales, nacionales o internacionales aplicables.

Las herramientas disponibles en la sección de Tools (generador de QR, contraseñas, hash SHA-256/512, Base64, UUID, Pomodoro, conversor de unidades, entre otras) se ofrecen de forma gratuita y sin garantías.

El operador no garantiza que los resultados de las herramientas sean precisos al 100% para usos críticos. Para aplicaciones que requieran alta exactitud (médica, financiera, legal), verifica los resultados con fuentes adicionales. El uso de estas herramientas es bajo tu propia responsabilidad.

06 Chatbot EMI IA

El chatbot EMI IA es un asistente de inteligencia artificial diseñado para ayudar con preguntas técnicas de programación y desarrollo web. Al usarlo, aceptas que:

  • Las respuestas son generadas por modelos de IA y pueden contener errores.
  • No debes usarlo para obtener asesoría médica, legal, financiera o en situaciones de emergencia.
  • Las conversaciones pueden ser procesadas por proveedores de IA de terceros.
  • Existe un límite de 30 mensajes por sesión para garantizar la disponibilidad del servicio para todos los usuarios.
  • No introduzcas información personal sensible, contraseñas o datos confidenciales en el chat.
