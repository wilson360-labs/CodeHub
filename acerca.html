En resumen: CodeHub es un proyecto personal de un desarrollador web en Guatemala que decide construir y compartir en abierto: herramientas gratuitas, guías honestas, apps open source y servicios de desarrollo web.

01 Quién está detrás

Detrás de CodeHub está Wilson.E, un desarrollador web que trabaja y responde desde Ciudad de Guatemala, con clientes en toda Latinoamérica y de forma remota. Mi trabajo diario combina tres frentes: construir applicationes web a medida para negocios, mantener herramientas y apps propias de código abierto, y escribir guías prácticas sobre seguridad digital y desarrollo.

Tecnologías con las que trabajo con más frecuencia: HTML5, CSS3, JavaScript moderno (sin frameworks pesados cuando el proyecto no los necesita), Node.js, bases de datos como Supabase/PostgreSQL y MongoDB, servicios como EmailJS y notificaciones push, y despliegue en Vercel y Cloudflare Pages. Este mismo sitio está construido con ese enfoque: rápido, portable y con foco en una buena experiencia móvil.

02 Qué es CodeHub

CodeHub empezó como un espacio para reunir herramientas que uso y que otros desarrolladores o personas comunes necesitan resolver sin instalar aplicaciones ni crear cuentas. Hoy es un conjunto de piezas que se complementan:

  • Herramientas web gratuitas: 38 utilidades que corren, en su mayoría, directamente en el navegador.
  • Guías: texto práctico sobre contraseñas, seguridad y lo que pasa en el navegador vs. en el servidor.
  • Open source: un catálogo de apps publicadas para que cualquiera las instale, use o estudie.
  • Servicios de desarrollo: proyectos web para negocios (tiendas, landing pages, dashboards) que financian que lo demás siga siendo gratuito.

Cada pieza se publica solo cuando funciona y se explica con claridad. Prefiero un proyecto pequeño bien terminado a una lista larga de pendientes a medias.

03 Qué puedes esperar

  • Transparencia: si una herramienta usa una API externa o envía datos, se dice en su propia tarjeta.
  • Privacidad por diseño: las herramientas de texto local (contraseñas, hash, UUID) no envían tus datos a ningún servidor.
  • Mobile first: todo se prueba desde 380px hasta pantallas de escritorio, en modo claro y oscuro.
  • Sin relleno: texto útil, no párrafos de relleno con palabras clave.
  • Actualizaciones constantes: el sitio se mejora con cada ciclo de trabajo y cualquier error reportado se atiende de forma prioritaria.

04 Privacidad y dinero

CodeHub se sostiene con dos fuentes: el desarrollo web para negocios y anuncios no intrusivos de Google AdSense. Eso permite que las herramientas sigan siendo gratuitas y sin registro.

Respecto a tus datos: no vendo información personal a nadie. Lo que recopilo y cómo se usa está documentado en la Política de Privacidad, y las condiciones de uso en Términos.

05 Cómo colaborar o contactarme

Si encontraste un error en una herramienta, tienes una idea para ampliarlas o quieres hablar de un proyecto web, el canal más directo es WhatsApp y el correo de abajo. También puedes usar el formulario de contacto del inicio si prefieres un mensaje estructurado.
